# Supreme Dungeon II — v1.0.0 (first public release)

The Throne Hall awaits: 3 chapters of procedural dungeon crawling, 5 combat spells, hireable allies, arena waves, the Supreme Mage's twisted events — and 4 endings.

## Highlights

- Chapters I–III: Catacombs, Royal Lands, Castle of the Supreme Mage
- Spell system with mana, statuses and scrolls; allies that fight and heal
- Special boss events, arena, garden, library, achievements, hall of fame, 3 save slots
- ESC pause menu with resume / exit to title
- Full English localization
- 30 automated gameplay tests, all passing
